# 다음 스텝: `ollama-api/app/prompts/summary.py` 요약·메타 튜닝 아이디어

코드는 건드리지 않고, **나중에 실험할 때** 참고용 체크리스트다.  
정본 파일: `ollama-api/app/prompts/summary.py`

## 1. 단문 vs 장문(map-reduce) **분량 지시 맞추기**

**현재**: `SUMMARY_SYSTEM_FINAL`은 “400~1000자 권장”, `summary_user_final_from_chunk_memos`는 “700~1100자, 각 단원 2~4문장”.  
같은 6단원 포맷인데 상한이 다르면 모델이 **짧은 경로와 긴 경로에서 톤·밀도가 달라질** 수 있다.

**다음에 바꿔볼 것**:  
한 번에 통일할지(예: 둘 다 “대략 N~M자, 단원당 문장 수 범위”) 정한 뒤, **단문/메모 합성 둘 다 같은 숫자**를 쓰도록 문구만 맞춰 본다.  
또는 의도적으로 다르게 둘 거면, system/user에 **“단문은 ○○, 장문 합성은 △△”**처럼 역할 차이를 한 줄로 명시한다.

---

## 2. **6단원 출력 형식**을 user 쪽에 더 고정하기

**현재**: `summary_user_single_document`는 “6단원 순서대로”와 2번 단원 조건만 있고, 헤더 형식(`## 제목` 등)은 `summary_user_final_from_chunk_memos` 쪽에만 비슷한 언급이 있다.

**다음에 바꿔볼 것**:  
단문 경로 user 프롬프트 끝에 **반드시 쓸 마크다운 뼈대**를 한 블록으로 붙인다 (예: `1. ## 제목` … `6. ## …` 템플릿).  
프론트·후처리가 특정 헤더에 의존한다면 **불일치·누락 단원**이 줄어드는지 A/B로 본다.

---

## 3. **부분 청크(`summary_user_partial`)** bullet 개수·우선순위 조정

**현재**: “최대 4~6개 bullet”, 4단 우선순위(식별·목적·제도·시행).

**다음에 바꿔볼 것**:  
- 장문에서 **식별정보 bullet이 과다**하면 “식별은 1 bullet로 통합, 나머지는 제도·시행 위주”처럼 상한을 더 빡세게.  
- 반대로 **시행일·부칙이 자주 빠지면** 4) 시행요소에 “반드시 1 bullet 이상 시도” 같은 문구를 추가해 본다.

---

## 4. **`METADATA_SYSTEM`의 `tl_summary`에 소형 예시 1세트 (few-shot)**

**현재**: 규칙은 길고 잘 적혀 있지만, 모델이 자주 틀리는 패턴(목차 복붙, 한 문장만, 마침표 부족)은 **텍스트 규칙만**으로 막는 중이다.

**다음에 바꿔볼 것**:  
시스템 프롬프트 하단에 **금지 예 1줄 + 좋은 예 4줄 샘플**(가짜 의안명·가짜 bc_id)을 넣어 본다.  
토큰 비용이 늘어나므로, **운영 모델에서만** 켜거나 짧은 예시만 넣는 식으로 단계적으로 시험한다.

---

## 5. **`metadata_user_prompt` 스니펫 전략** 실험

**현재**: `_metadata_snippet_from_summary`는 길면 앞·절반 + `...[중략]...` + 뒤·절반.

**다음에 바꿔볼 것**:  
- 요약 중 **“제안이유·주요내용” 구간**이 잘리는 경우가 많으면, 스니펫을 **키워드 앵커 기반**(해당 구간 우선 포함)으로 바꾸는 안을 `summary.py`가 아니라 **함수 로직**에서 할 수도 있지만, 우선은 프롬프트에 **「중략 이후도 요약 본문 근거를 쓸 것」** 한 줄을 보강해 효과가 있는지 본다.  
- 또는 `max_summary_chars`를 파이프라인 기본값과 함께 **소폭 상향**해 메타 입력 정보량만 늘려 보고, `tl_summary` 복붙·환각 비율을 비교한다.

## 참고

- 실제 배포 후처리는 `app/vllm/summary/postprocess.py` — 프롬프트만 바꿔도 안 고쳐지는 오류는 그쪽과 짝을 이뤄 조정한다.  
- 배치·학습 데이터는 `metadata` 쪽 스크립트가 같은 `summary.py`를 import 하므로, **프롬프트 수정 후 JSONL은 재생성**하는 것이 안전하다.
